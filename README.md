# ai_for_sustainability
I am doing these tasks to enhance my knowledge and practice on Geospatial data. Learning to visualize data using python libraries such as GeoPandas and Matplotlib. Also, it's my first time training a Deep Learning Model. 
## Q1: Spatial Reasoning
- Plotted Delhi-NCR shapefile
- Created 60×60 km grid (EPSG:32644)
- Filtered satellite images inside region

## Q2: Label Construction
- Extracted 128×128 land-cover patches from ESA raster
- Assigned dominant (mode) class
- Mapped ESA codes to simplified categories
- Performed 60/40 stratified train-test split

## Q3: CNN Model
- Implemented custom CNN
- Achieved:
  - Test Accuracy: ~0.85
  - F1 Score: ~0.84
- Displayed confusion matrix

## Key Insight
Cropland dominates due to spatial extent of agricultural land in NCR.
